MANIFEST.md

El texto que une a los 11 módulos.

El conocimiento y la conectividad no deberían tener una licencia restrictiva.
Durante décadas, el acceso al ecosistema digital se ha tratado como un privilegio de pago, cerrando puertas y aislando comunidades enteras.

Creemos en un mundo donde el acceso a la red sea un estándar libre, modular y accesible para cualquier persona, sin importar su código postal.
La brecha digital es un sistema privativo que vamos a desmantelar juntos.

No pedimos permiso para conectar.
Compartimos las llaves, liberamos el conocimiento y compilamos oportunidades.

Somos Código Común. Hackeemos la brecha digital.

arquitectura/

La brecha digital se trata como un bug del sistema: se corrige entre todos, de forma distribuida.

Hub web central

  • Repositorio maestro alojado en GitHub Pages.
  • Índice con el estado de cada módulo.
  • Recursos liberados: PDFs, guías y kits descargables.

11 módulos distribuidos

  • Cada uno gestiona sus redes: Facebook, Instagram, X y TikTok.
  • Autonomía temática, alineada a la sombrilla.
  • Envían tráfico al Hub y el Hub reparte audiencia entre ellos.
